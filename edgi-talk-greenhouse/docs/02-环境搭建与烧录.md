# 02 · 环境搭建与烧录（从零到原版小智跑通）

> 目标：Windows 上装好 RT-Thread Studio，让 Edgi Talk 跑起**原版**小智固件并完成配网绑定。
> 之后回到 [`overlay/INTEGRATION.md`](../overlay/INTEGRATION.md) 集成本项目。
> 本文是官方文档的整理版，细节以官方文档站为准：
> https://rt-thread-studio.github.io/sdk-bsp-psoc_e84-edgi-talk/latest/component/Edgi_Talk_M55_XiaoZhi/README.html

## 1. 你需要准备

- Windows 10/11 电脑
- Edgi Talk 板（Type-C 线连接板载 KitProg3 调试口）
- 2.4GHz WiFi（板载 WiFi 6 模组 CYW55512，配网页面建议选 2.4G 频段）
- 外接扬声器（板载 1W 功放**无喇叭**，接 3.5mm 或端子喇叭才能听到声音）

## 2. 安装工具链

1. 下载安装 **RT-Thread Studio ≥ 2.2.9**（官网 https://www.rt-thread.org/page/studio.html）。
2. 克隆 BSP 仓库（或下载 zip 解压）：

```
git clone https://github.com/RT-Thread-Studio/sdk-bsp-psoc_e84-edgi-talk.git
```

3. Studio 中 **文件 → 导入 → RT-Thread 项目导入**（Existing Projects into Workspace），
   选择 `projects/Edgi_Talk_M55_XiaoZhi`。

## 3. 多核启动链：先烧 M33，再烧 M55（仅首次）

PSoC Edge E84 启动顺序为 Secure M33 → 非安全 M33 → M55。**M55 小智固件必须依赖
M33 侧固件先把它带起来**：

1. 导入 `projects/Edgi_Talk_M33_Template` 工程，编译烧录（Studio 一键下载，
   经板载 KitProg3/OpenOCD）。
2. 若 M33 工程中 "Enable CM55 Core" 选项未开，先开启再烧一次（详见官方 FAQ）。

> 出厂已烧好整套固件的板子，此步通常可跳过——直接烧 M55 小智工程即可。

## 4. WiFi 固件 blob（仅首次 / 升级 WiFi 固件时）

WiFi 模组固件资源（whd_firmware / clm / nvram）存放在 FAL 分区，需要用 Xshell
等终端的 **YMODEM** 发送并写入（出厂固件已含，一般无需重做）：

1. 串口终端连 KitProg3 虚拟串口（115200-8N1）。
2. 按官方文档执行三条命令并 YMODEM 发送对应文件到 `whd_res_download` 指定分区。
   具体命令以官方 README "WiFi 固件下载" 章节为准。

## 5. 编译烧录小智固件

1. Studio 中选中 `Edgi_Talk_M55_XiaoZhi` → 编译。
2. 一键下载（KitProg3 + OpenOCD / DAPLink）。
3. 复位，屏幕出现表情与 "初始化中..." 即启动成功。

## 6. 配网与绑定（首次）

1. 屏幕提示进入配网时（或按官方按键组合），手机/电脑连接板子热点（默认
   `RT-Thread-AP`，密码见屏幕）。
2. 浏览器打开 `192.168.169.1`，选择家里/大棚的 2.4GHz WiFi 并输入密码。
3. 联网成功后屏幕进入 Standby；按下用户按键，设备朗读 6 位激活码。
4. 电脑登录 [xiaozhi.me](https://xiaozhi.me) → 控制台 → 智能体 → 添加设备 → 输入激活码绑定。

## 7. 集成本项目

原版跑通后，按 [`overlay/INTEGRATION.md`](../overlay/INTEGRATION.md) 两步集成，
再按 `03-智能体人设配置.md` 配置"大棚管家"人设。

## 8. 常见问题

| 现象 | 处理 |
|---|---|
| 下载失败/连不上调试器 | 换 USB 线/口；确认 KitProg3 固件正常（官方 FAQ 有 KitProg3 升级说明） |
| M55 固件烧写成功但不启动 | M33 启动固件缺失或未开 CM55 Core，回到第 3 节 |
| 配网页打不开 | 确认连的是板子 AP；浏览器输 `192.168.169.1`（不是 192.168.4.1） |
| 连不上小智服务器 | WiFi 需能访问公网；服务器为 `api.tenclass.net:443`，检查路由器防火墙 |
| `greenhouse_status` 显示 `no (i2c1/i2c2/i2c0 no ACK)` | 板上未焊载 AHT20 或在拓展板：外接 AHT20 模块到 40-pin I2C 引脚；读失败会每轮自动重探测 |
| 温湿度一直是 0 | AHT20 读取失败会走合理性过滤被丢弃：查 i2c1 是否被其他外设占用、板子是否为早期批次（无 AHT20） |
