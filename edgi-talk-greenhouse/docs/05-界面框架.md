人设仍是「菜园管家」。屏幕是 LVGL，横屏 800×480。源码在小智工程里，不在本仓库的 `overlay/`：

`projects/Edgi_Talk_M55_XiaoZhi/applications/xiaozhi/ui/`

本机树：`/home/Srakoul/Documents/Codex/2026-09-27/b/work/sdk-bsp-psoc_e84-edgi-talk`

同一份界面源码也放在本仓库 `screen/ui/`，方便脱离 SDK 阅读。改界面时两处一起改，尺寸只改 `gh_ui_layout.h`。

## 文件

| 文件 | 职责 |
|---|---|
| `gh_ui_layout.h` | 唯一的尺寸表。页边、气泡、管家、下排参数宽度都在这里 |
| `xiaozhi_ui.c` | 引擎：线程、消息队列、四个页面、告警栏、气泡。官方 `xiaozhi_ui_*` API 不变 |
| `gh_ui_pages.h` | 页面插件。新页面实现 `create/update`，再注册进 `s_pages[]` |
| `gh_page_main.c` | 主页：空气温度、湿度、当前作物、报警阈值、小智提醒 |
| `gh_page_net.c` | WiFi、已存热点、IP、小智服务器、配网热点 |
| `gh_page_cal.c` | 时钟和当月月历。RTC 未设时提示用 `date` |
| `gh_page_crop.c` | 番茄/黄瓜/辣椒/叶菜/草莓/通用。点一下写入温度报警区间 |
| `gh_butler.c` | 右下角 120×128 的草帽管家：呼吸、眨眼、说话张嘴、高兴挥手 |

官方 3D emoji 不画在这个界面上。缩进小容器后它不渲染，全屏时又占掉半块屏。

## 画面

```
菜园管家            状态                 电池
[有报警才出现的红条]
温度          湿度
当前作物      适温 / 报警阈值
小智提醒（环境正常或报警原文）          [气泡 200×52]
土壤未接  光照未接  CO2未接             [管家]
主页  网络  日历  作物
```

气泡挂在最上层，只在管家头顶。不说话约 4 秒后消失，配网信息除外。下排文字宽度是 `GH_LOWER_W`，停在气泡左边，所以作物参数还在。

报警没解除时，气泡消失后管家保持惊讶，而不是回到微笑。

## 数据

只用板上真实模块。

- 温度：AHT20 空气温度。没有 AHT20 时用 LSM6DS3 管芯温度，卡片上写 IMU。
- 湿度：只有 AHT20 在线才有数，否则 `--`。
- 土壤、光照、CO2：没有传感器，界面写「未接」，不生成假数。
- 阈值：作物页点击，或语音调用 `self.greenhouse.set_thresholds`。主页每秒回读，和 AI 改过的值保持一致。
- 提醒：`greenhouse_build_alert_text()`。同一段话进告警栏、气泡和管家表情。

AI 工具名和 `docs/03-智能体人设配置.md` 一致：`get_report`、`get_temperature`、`get_humidity`、`get_alarm_status`、`set_thresholds`。报告里会说明土壤/光照/CO2 没装，避免模型编数。
