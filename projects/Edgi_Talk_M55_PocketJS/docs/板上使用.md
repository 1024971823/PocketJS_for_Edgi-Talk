# 板上使用

上电后进入主页。画面是 400×240 的界面，放大到 800×480 的屏。界面上的字是英文和数字。

页面点进去是立刻切换的，没有滑动过渡。一个页面第一次打开会停顿一两秒（要在板上创建界面），之后再进就快。开始一局游戏时，主页这些页面会卸掉，所以从结算回到选歌也会再停一下。

## 主页

| 位置 | 作用 |
| --- | --- |
| 左上角头像和名字 | 固定标识，不可点 |
| 天气胶囊 | 联网后显示气温。目前经常是 `--`，不影响别的功能 |
| Wi-Fi 胶囊 | 已连接时显示网络名，没连上显示 Setup 或 Offline。点进去是设置 |
| 日期胶囊，例如 `OCT 7` | 日历。还没对上时间时显示 `-- --` |
| 菜单按钮 | 设置 |
| BEAT DASH 卡片上的 PLAY | 选歌。在主页向上滑也是选歌 |
| 右侧四环（CPU、RAM、TEMP、FLASH） | 板子自己的占用。FLASH 是 `/flash` 已用百分比。点这块区域进入电脑监控页 |
| 底部音乐条 | 播放、上一首、下一首、音量 |

音乐条中间是播放/暂停，左右箭头换曲，`-` / `+` 调音量。默认是内置的 Demo melody。游戏开始后这一路声音让给游戏，结束后恢复。

### 播放器里的歌

电脑上位机用蓝牙把歌压成 MP3 传到板子 flash（`/flash/m_歌名.mp3`）。也可以把 WAV 放到 `/sdcard/music`。两处加起来最多 16 首，外加内置的 Demo melody：

- SD 卡上的 WAV：单声道、16-bit PCM，采样率 16、24、48 或 96 kHz
- 蓝牙传上来的歌是单声道 MP3，存在 `/flash/m_歌名.mp3`

开机时会扫这两处，停止播放期间也会再扫。

## 选歌和打歌

选歌页四张卡：

| 卡 | 曲子 | 速度 | 难度 |
| --- | --- | --- | --- |
| EASY | Sunny Steps | 112 BPM | 1 |
| NORMAL | Neon Pulse | 128 BPM | 2 |
| HARD | Cat Rush | 150 BPM | 3 |
| PC | 电脑传上来的自定义曲 | 谱面里写的 | 没传过显示 “No song yet” |

点一张卡进入舞台。**第一下点击是开始**，不是打音符。之后：

- 上半屏打空气轨（蓝色），下半屏打地面轨（红色）。判定线在左边。
- 左上角 EXIT 退出，不记成绩。
- 误差 90 ms 以内是 PERFECT（300 分，HP +2），170 ms 以内是 GREAT（150 分），更远是 MISS（连击清零，HP −10）。
- 连击加分是 `连击数（最多按 100）× 3`。
- 大音符打中之后 350 ms 内，再点同一条轨道，额外 +200（BONUS）。
- HP 从 100 开始，到 0 本局失败。

打完进入结算：

- 标题是 STAGE CLEAR 或 STAGE FAILED。
- 准确率 = `(PERFECT 次数 + GREAT 次数 × 0.6) / 总音符数`。
- 没失败时：≥95% 为 S，≥85% 为 A，≥70% 为 B，其余为 C。失败是 F，不刷新最高分。
- RETRY 再打同一首，SONGS 回选歌。

最高分按槽位保存：0、1、2 是三首内置曲，3 是 PC 卡。

### 音符和声音对不齐

音符跟着板上合成器的时钟走，固件里按大约 100 ms 的输出延迟预留了一段。听起来偏了就去设置里调 AUDIO OFFSET，每次 10 ms，范围 −200 到 200：

- 音符看起来比声音晚：把数字调高。
- 音符看起来比声音早：把数字调低。

## 日历

从主页日期胶囊进入。

- 标题是月份和年份，例如 `OCT 2026`。
- 今天是深青色实心圆、白字。只有正在看的这个月会标今天。
- `<` 和 `>` 翻月，TODAY 回到本月，`< Home` 回主页。
- 周日和周六的日期颜色更淡。不属于本月的格子是空的。
- 时间还没同步时，格子是空的，中间写 “Waiting for time sync”。

时间从两个地方来，后到的电脑时间会盖过天气服务器十分钟：

1. 板子连上能上网的 Wi-Fi 后，从天气请求的 HTTP `Date` 头读取，按 UTC+8 写入时钟。
2. 电脑上位机每发一次状态，也会带上电脑的时间和时区。

## 电脑监控页

从主页右侧四环，或设置页的 “PC Monitor >” 进入。这里显示的是**电脑**的状态，不是板子自己的。电脑上要先跑上位机，见 [电脑上位机](电脑上位机.md)。

- 四个环：CPU、RAM、DISK、TEMP。读不到温度时 TEMP 是 N/A。
- 下面两行是内存和磁盘的已用 / 总量。
- 右上角：8 秒内收到过数据显示 ONLINE（绿点），收到过但超时是 OFFLINE（红点），从没收到过是 WAITING。
- HOST 是电脑名，右边是距上次数据的秒数。

## 设置

- NETWORK：Connected 时给出 SSID 和 IP。还在热点配网时给出热点名、密码，以及要在浏览器打开的 `http://192.168.169.1`。
- AUDIO OFFSET：见上面。
- PC PAIR CODE：六位数字。上传谱面、删除谱面、推送电脑状态都要这个码。第一次开机生成，之后不变。
- “PC Monitor >”：进入电脑监控页。

这些存在板子的 flash 里：

| 文件 | 内容 |
| --- | --- |
| `/flash/pocketjs_game.bin` | 最高分、评级、音频偏移、配对码 |
| `/flash/pocketjs_song.json` | 自定义曲 |
| `/flash/pocketjs_wifi.bin` | 保存的 Wi-Fi |

## 连 Wi-Fi

没有保存过的网络时，板子自己开热点：

- 名称是 `EdgiTalk-` 加上芯片编号后 6 位，例如 `EdgiTalk-80D47D`。
- 密码是 `Edgi` 加上芯片编号，设置页里会写出来。
- 手机或电脑连上这个热点，浏览器打开 `http://192.168.169.1`，选家里的网络并填密码。

连上之后热点会关掉，设置页变成 Connected，并显示板子在局域网里的 IP。HTTP 服务仍在 80 端口，供上位机使用。配网页只在热点上提供，连上路由器之后用浏览器打开板子 IP，看到的是一段说明，不是配网表单。
