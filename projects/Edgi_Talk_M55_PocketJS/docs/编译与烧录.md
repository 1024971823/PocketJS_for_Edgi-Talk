## 只改了界面或谱面

先打 `.pocket`，再编固件。固件每次编译都会把当前的 `.pocket` 重新嵌进去。

```sh
cd /home/Srakoul/Documents/Codex/2026-09-27/b/work/pocketjs
~/.bun/bin/bun tools/pocket.ts build \
  --host-profile apps/edgitalk-m55-smoke/pocket.host.json \
  --manifest apps/edgitalk-m55-smoke/pocket.json
```

产物：`apps/edgitalk-m55-smoke/dist/edgitalk-m55-smoke.pocket`。

仪表环的图片由 `tools/assets/make_rings.py` 生成（灰轨道一张，青色填充 0% 到 100% 每 5% 一张，另有 `@2x`）。改了生成脚本才需要重跑，然后重新打 `.pocket`。

## 烧录

板子用 KitProg3。第一次先装 udev 规则（会要 sudo），拔插一次，再确认探针能看到：

```sh
/home/Srakoul/Documents/Codex/2026-09-27/b/work/install-kitprog3-udev-rule.sh
/home/Srakoul/Documents/Codex/2026-09-27/b/work/flash-xiaozhi-daplink.sh probe
```

只烧这块 M55 固件，不动 M33：

```sh
cd /home/Srakoul/Documents/Codex/2026-09-27/b/work
M55_PROJECT=Edgi_Talk_M55_PocketJS ./flash-xiaozhi-daplink.sh m55
```

不设 `M55_PROJECT` 时，脚本烧的是 `Edgi_Talk_M55_XiaoZhi`，不是这个工程。

| 参数 | 做什么 |
| --- | --- |
| `probe` | 只连上，打印 flash 和内核 |
| `reset` | 复位后跑起来 |
| `m55` | 擦写 M55 镜像再复位 |
| `m33` | 擦写 M33 基础镜像 |
| `all` | 先 M33 再 M55 |

镜像在 `projects/Edgi_Talk_M55_PocketJS/Debug/rtthread.hex`。烧录日志里的 `kitprog3: failed to acquire the device` 出现在已经写完、探针断开的时候，前面有 `wrote ... bytes` 就是成功。

串口（115200，设备名按实际的来）：

```sh
./serial-edgi-talk.sh /dev/ttyACM0 115200
```

PocketJS 大约每 5 秒打一行 `frames=... ui=... lcd=...`。游戏进行中不打，避免统计本身占时间。
