# 编译与烧录

默认布局假定本工程位于 `sdk-bsp-psoc_e84-edgi-talk/projects/`，外部依赖和工具位于上两级的 `WORK_ROOT`。所有常用操作都从本工程根目录运行脚本，不需要写个人绝对路径。

| 依赖 | 默认位置 | 覆盖变量 |
| --- | --- | --- |
| 本固件工程 | 当前目录 | 不需要 |
| PocketJS、界面和 Rust 静态库 | `WORK_ROOT/pocketjs` | `POCKETJS_ROOT` |
| QuickJS-ng | `WORK_ROOT/quickjs-ng` | `QUICKJS_ROOT` |
| GNU Arm 工具链 | `WORK_ROOT/toolchains/.../bin` | `RTT_EXEC_PATH` |
| Python | `WORK_ROOT/edgi-talk-py312/bin/python` | `EDGI_TALK_PYTHON` |
| Bun | `~/.bun/bin/bun` | `BUN_BIN` |
| 烧录脚本 | `WORK_ROOT/flash-xiaozhi-daplink.sh` | `EDGI_TALK_FLASH_TOOL` |

## 编译

改了 TypeScript、界面资源或谱面时，打 `.pocket` 并编固件：

```sh
tools/build.sh -j8
```

只改固件 C 时，复用已有 `.pocket`：

```sh
tools/build.sh --no-ui -j8
```

`tools/build.sh` 会依次：

1. 用 `bun` 构建 `edgitalk-m55-smoke.pocket`（`--no-ui` 时跳过）。
2. 生成嵌入汇编，并把 `.incbin` 改写成相对工程根目录的路径。
3. 校验 `tools/dependencies.lock` 中的外部 commit 和实际构建输入哈希。
4. 用 SCons 编出 `Debug/rtthread.hex`。

需要探针模拟点击时（见 [性能测量](性能测量.md)）才加调试开关，日常烧录不要加：

```sh
POCKETJS_DEBUG_TOUCH=1 tools/build.sh --no-ui -j8
```

### 外部依赖基线

`tools/dependencies.lock` 记录 PocketJS / QuickJS-ng 的 commit，以及实际链接进固件的 `.pocket` 和两份 Rust 静态库的 SHA-256。确认依赖或预编译库是有意升级后更新：

```sh
python3 tools/check_dependencies.py --update
```

界面 TypeScript 当前还在 PocketJS 工作树的未跟踪目录中。要得到严格可复现的发布构建，应先把 `apps/edgitalk-m55-smoke/` 纳入 Git 或随工程归档；哈希锁能检测产物变化，但不能替代源码版本记录。

Rust 静态库不是每次编固件都会重建。只有 `pocketjs/hosts/esp-idf/native/` 下的源码变化时才需要：

```sh
rustup target add thumbv8m.main-none-eabihf
cd "$POCKETJS_ROOT/hosts/esp-idf/native/ui-core"
cargo build --release --target thumbv8m.main-none-eabihf
cd ../render-rgb565
cargo build --release --target thumbv8m.main-none-eabihf
```

之后从本工程根目录运行 `python3 tools/check_dependencies.py --update`，再编译。

## 自动检查

不需要板子的检查一次跑完：

```sh
tools/ci.sh
```

它检查依赖锁、用户绝对路径、Python 语法和上位机单测，编译并运行桌面合成器测试，最后用 `tools/build.sh --no-ui -n` 做 SCons 构建图检查。需要完整 CI 构建时，在同一环境直接运行 `tools/build.sh --no-ui -j8`。

## 烧录

板子用 KitProg3。第一次先装 udev 规则（会要 sudo），拔插一次，再确认探针：

```sh
tools/flash.sh probe
```

只烧这块 M55 固件，不动 M33：

```sh
tools/flash.sh m55
```

`tools/flash.sh` 固定使用 `M55_PROJECT=Edgi_Talk_M55_PocketJS`，不会误烧 `Edgi_Talk_M55_XiaoZhi`。

| 参数 | 做什么 |
| --- | --- |
| `probe` | 只连上，打印 flash 和内核 |
| `reset` | 复位后跑起来 |
| `m55` | 擦写 M55 镜像再复位 |
| `m33` | 擦写 M33 基础镜像 |
| `all` | 先 M33 再 M55 |

镜像在 `Debug/rtthread.hex`。烧录日志里的 `kitprog3: failed to acquire the device` 出现在已经写完、探针断开的时候，前面有 `wrote ... bytes` 就是成功。

串口 115200，设备名按实际的来：

```sh
"$WORK_ROOT/serial-edgi-talk.sh" /dev/ttyACM0 115200
```

PocketJS 大约每 5 秒打一行 `frames=... ui=... lcd=...`。游戏进行中不打，避免统计本身占时间。
