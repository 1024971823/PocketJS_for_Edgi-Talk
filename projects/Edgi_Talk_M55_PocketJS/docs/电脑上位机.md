# 电脑上位机

`tools/edgitalk-companion/edgitalk.py` 用 Python 3 标准库和板子说话。装了 `psutil` 时，读本机 CPU、内存和温度会优先用它；没装也能跑。

电脑和板子要在同一个局域网。板子的 IP 和六位配对码在设置页。

```sh
cd tools/edgitalk-companion
```

下面的命令都可以在前面加 `--host 192.168.1.20 --token 123456`，临时指定板子，不改已保存的配对。`--port` 默认 80。

请求直连板子，不走环境变量里的 `http_proxy` / `https_proxy`。开着代理时，如果没绕过，私有地址会得到 502。

## 第一次连上

```sh
python3 edgitalk.py discover
python3 edgitalk.py pair 192.168.1.20 123456
python3 edgitalk.py status
```

`discover` 向 UDP 47808 广播 `EDGI?`，约 1.5 秒（`--timeout` 可改）。板子在省电时前几个包可能丢，多试一次。

`pair` 把地址和配对码写到 `~/.edgitalk.json`（权限 600）。之后 `status`、`scores`、`push`、`stats` 都用这份配置。

`status` 打印设备名、是否已有自定义曲、是否正在游戏。`scores` 打印 8 个槽位的最高分和评级字母，前四个对应三首内置曲和 PC 卡。

## 把本机状态发到板子

板子自己不会来拉电脑的数据。电脑推给 `PUT /api/pc`，主页点进 “PC MONITOR” 就能看到。

```sh
python3 edgitalk.py stats                 # 发一次
python3 edgitalk.py stats --watch         # 每 2 秒发一次，Ctrl-C 停止
python3 edgitalk.py stats --watch --interval 5
python3 edgitalk.py stats --name my-pc    # 板上显示的名字，最长 16 个英文数字
python3 edgitalk.py stats --no-time       # 不顺便校准板子时钟
```

每次发送包含：

| 字段 | 含义 |
| --- | --- |
| `cpu` | 0–100，按两次采样之间的差值算，所以第一次可能偏低 |
| `ramPct` / `ramUsedMb` / `ramTotalMb` | 内存。已用按“总量减可用”算，不含可回收缓存 |
| `diskPct` / `diskUsedGb` / `diskTotalGb` | 系统盘，Linux 是 `/`，Windows 是系统盘 |
| `temp` | CPU 温度（℃）。读不到是 −1，板上显示 N/A |
| `t` / `tz` | 当前 Unix 秒，和本地时区相对 UTC 的分钟数。板子用它设时钟 |

Linux 上没装 `psutil` 时，CPU 和内存来自 `/proc`，温度来自 `/sys/class/hwmon` 和 `thermal_zone`。Windows 上用系统 API，没有 `psutil` 时温度通常是 N/A。

板上超过 8 秒没收到新数据，监控页从 ONLINE 变成 OFFLINE，数值留着。

## 页面

```sh
python3 edgitalk.py console
```

`gui` 打开同一个页面。不需要 Tk。进程只在 `127.0.0.1` 上提供页面，并打开浏览器。地址不用填。

打开后先找蓝牙广播名 `EdgiTalk`（电脑需要有蓝牙适配器和 BlueZ，不用装额外的库）。找到后标题下写出蓝牙地址。你只填设置页右侧的六位配对码，点连接。状态数据包走蓝牙，板子上的 Wi-Fi 同时开着，互不影响。找不到蓝牙时才退回 Wi-Fi 扫描。自定义曲仍然用 Wi-Fi，不走蓝牙。

板子上电后要先把蓝牙控制器固件下载进去，用时约 45 秒。设置页里 HOST 下面出现 `BT EdgiTalk` 之后再点连接。配对码不对的数据包会被板子丢弃，不会显示到电脑监控页。

板子的串口日志里能看到这几行：`download window open`、`patch download ok (519 records)`、`advertising EdgiTalk`、`stats accepted` 或 `stats rejected`。

下面两块一直都在：

- **这台电脑**：四个数是本机当前值。发给板子按 1 秒、2 秒或 5 秒推送，再点一次停止。只校准时间把电脑时钟发给板子。
- **一首曲子**：选择 MIDI 或 JSON，填标题（最多 12 个字符）和难度 1–3（只影响从 MIDI 生成的谱）。选中后立刻显示 BPM、音符数和大小。推到板子、从板子取回、删掉、看最高分的结果写在按钮下面。删掉需要点两次。

## 自定义曲

命令行做同样的事：

```sh
python3 edgitalk.py demo -o chart.json          # 写一个能直接推的例子
python3 edgitalk.py validate chart.json         # 不连板子，只检查格式
python3 edgitalk.py push chart.json             # 出现在选歌页的 PC 卡
python3 edgitalk.py pull out.json               # 不写路径就打印到终端
python3 edgitalk.py clear

python3 edgitalk.py make-chart song.mid -o chart.json --title "My Song" --level 2
```

`make-chart` 读标准 MIDI，取音符最多的一条旋律轨，按至少约 170 ms 的间隔收成单点，并自动配简单的贝斯和鼓。`--bpm` 覆盖文件里的速度，`--lead-in` 是第一个音符前空多少个十六分音符（默认 16）。标题里的非 ASCII 字会被换成 `?`。

游戏进行中不能上传或删除，板子会拒绝。配对码连续错 5 次，30 秒内连正确的码也不收。

### 谱面格式

一个 JSON 对象，体积不超过 96 KiB，音频事件不超过 2000 条。

```json
{
  "title": "PC Demo",
  "bpm": 120,
  "level": 2,
  "steps": 160,
  "notes": [16, 0, 20, 1],
  "events": [16, 0, 72, 2, 90]
}
```

- `bpm`：60 到 240。`level`：1 到 3。`steps` 可以不写，板子会按最后一个音符估计长度。
- `notes`：`[拍, 类型, 拍, 类型, ...]`，至少一对。一拍是一个十六分音符。类型 `0` 地面、`1` 空气、`2` 大地面、`3` 大空气。
- `events`：`[拍, 音色, 音高, 时值, 音量, ...]`，五个一组。音色 `0` 主旋律、`1` 贝斯、`2` 鼓。鼓的音高是 `0` 底鼓、`1` 军鼓、`2` 踩镲；旋律和贝斯是 MIDI 音高 12–108。时值按拍计，音量 1–127，写 0 会当成 90。

## 没有板子时自测

```sh
python3 edgitalk.py mock
```

假板子听在 `http://127.0.0.1:8080`，配对码 `123456`，发现端口仍是 47808。另开一个终端：

```sh
python3 edgitalk.py --host 127.0.0.1 --port 8080 --token 123456 status
python3 edgitalk.py --host 127.0.0.1 --port 8080 --token 123456 push chart.json
```

单测（会自己起一个假板子，不占用 8080）：

```sh
python3 -m unittest test_edgitalk.py
```

## 板子上的接口

上位机用的就是这些。自己写程序时同样带 `X-Token`， body 是 JSON。

| 方法 | 路径 | 要配对码 | 作用 |
| --- | --- | --- | --- |
| GET | `/api/status` | 否 | 设备名、IP、是否在玩、自定义曲有没有 |
| GET | `/api/scores` | 否 | `best` 数组和 `rank` 字符串 |
| GET | `/api/pc` | 否 | 最近一次电脑状态和 `ageMs`（从没收到是 −1） |
| PUT | `/api/pc` | 是 | 电脑状态，body 不超过 512 字节，必须有整数 `cpu` |
| GET | `/api/song` | 否 | 下载自定义曲原文；没有时 404 |
| PUT | `/api/song` | 是 | 上传，要有 `Content-Length`，8 字节到 96 KiB |
| DELETE | `/api/song` | 是 | 删除自定义曲 |

发现：向广播地址的 UDP 47808 发 `EDGI?`，板子回一段 JSON，里面有 `device`、`name`、`port`。
