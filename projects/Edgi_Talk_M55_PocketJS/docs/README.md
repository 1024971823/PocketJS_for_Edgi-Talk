# 使用文档

Edgi-Talk M55 上的 PocketJS 固件：主页仪表盘、Beat Dash 节奏游戏、日历、电脑状态页，以及电脑上的上位机。

| 文档 | 给谁看 |
| --- | --- |
| [板上使用](板上使用.md) | 开机之后在屏幕上怎么玩、怎么配网、日历和电脑监控页 |
| [电脑上位机](电脑上位机.md) | 在同一局域网里发现板子、看成绩、推谱、把本机 CPU/内存/磁盘/温度发给板子 |
| [编译与烧录](编译与烧录.md) | 改完界面或固件之后怎么打包、编译、只烧 M55 |
| [桌面预览](桌面预览.md) | 不接板子，在电脑上跑同一份界面并出截图 |
| [性能测量](性能测量.md) | 接 KitProg3，在板子上测帧率和截屏 |

界面源码在仓库外的 `b/work/pocketjs/apps/edgitalk-m55-smoke/`，那边的 `README.md` 只说明目录和渲染约束。

工程模块边界、源码-only/完整构建模式和跨语言契约见仓库根目录的 [`工程框架.md`](../../../docs/工程框架.md)。
